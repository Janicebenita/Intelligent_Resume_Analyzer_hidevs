# Repository artwork

- `rolelens-hero.png`: conceptual brand illustration generated with the built-in image-generation tool. This is not a product screenshot. The generation prompt is preserved in `hero-prompt.txt`.
- `feature-cards.png`: original code-drawn capability cards, generated by `python scripts/build_readme_assets.py` with Pillow.
- `workflow.gif`: original looping animated pipeline illustration from the same script. It represents Parse → Match → Inspect → Export; it is not a screen recording or a performance measurement.
- `rolelens-journey.gif`: a more detailed ten-stage animation, inspired by the user's reference layout and adapted to the implemented resume-analysis pipeline. `journey-poster.png` is its static accessible companion. Animated packets and highlights are explanatory artwork rather than runtime telemetry. Shared-palette encoding reduces the download size and avoids palette flicker.
- Actual application screenshots are stored separately in `docs/screenshots/` and labeled as such in the README.

The existing generated image was copied into the repository without modifying it. These assets contain no real candidate data and make no numerical accuracy or evaluation-score claims.

The detailed journey holds each stage for six seconds, then animates a 0.9-second transition. Its complete ten-stage loop lasts 69 seconds. This reading-first pacing was requested by Janice; preserve it when regenerating the GIF.
